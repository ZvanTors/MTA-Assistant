# MTA Assistant

A simple Windows tool for MTA:SA players.

**Version:** 1.0.0
**Made By:** AmooReza

## Features

- Stores your MTA:SA folder path in the Windows registry.
- **Calculating the work report** — counts PNG screenshots in the
  `Arrest`, `Kill`, `Shift`, `TakeGun` and `Wanted` folders and
  calculates total earnings.
- **Create Work Report** — creates a folder on your Desktop named
  after your in-game name, copies the category folders into it,
  and compresses it into a `.zip` file.
